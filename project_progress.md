### Packages
#### biopython
BioPython is an open-source collection of tools for computational biology and
bioinformatics. It provides modules and classes to manipulate biological data, 
perform sequence analysis, work with 3D structures of biological molecules, 
and more.
#### Streamlit
Streamlit is a Python library for creating web applications for data
science and machine learning with minimal effort. It allows you to turn data scripts
into shareable web apps quickly. You can build interactive and customizable
dashboards with just a few lines of code.
